# 常见问题

## 安装依赖失败

先确认 Node 与 pnpm 版本、工作目录和网络。`--frozen-lockfile` 失败时不要立即删除锁文件；它可能提示清单被改动、用了错误的 pnpm，或克隆不完整。

Electron 是单独下载的运行时。代理、网络限制和不同平台原生依赖都可能使安装失败。按终端中具体失败的包处理，别把其他机器的依赖复制过来。资源不足时使用 `pnpm typecheck:safe` 和 `pnpm test:run:safe` 限制并发。

## 启动卡在素材下载

首次启动需要 Live2D Cubism SDK 与示例模型。检查错误中的下载来源与网络，并遵守其授权。不要把不明来源的脚本当作 SDK，也不要提交缓存。如果使用已有合法资源，应按下载插件的目录约定放入本地缓存。

## 5173 端口被占用

停止之前启动的开发进程，再执行 `pnpm dev`。应用固定来源是设置持久化的一部分；开发配置会在端口占用时报错，不自动切换到 5174。

## 页面可以打开，模型不能回复

检查 **服务商** 配置与 **思考** 模块是否选择了同一个有效模型。Base URL、密钥和模型 ID 都需要正确；接口可用不等于当前模型支持工具或视觉。

默认本机官方 API 没有对应后台时，登录或官方云会失败。这时先使用自配服务，不要把服务连接问题当作客户端安装不完整。

## 合成动作或视觉不可用

- 先确认当前角色包含所配置的表情、motion 或动作卡，并在设置页单独预览。
- 视觉需配置渠道并开启，图片不能超出客户端或供应商限制。
- 自动截图默认关闭，需要显式选择来源、频率，并完成必要的费用授权。
- 多窗口切换或取消请求后，旧结果可能被主动丢弃，防止覆盖当前会话。

## 旧电脑、显卡或 CPU 问题

先获取应用的脱敏运行诊断，核对 OS、架构、Electron / Chromium、WASM、WebGL 和音频能力。能力检测用于定位故障，不能使 Electron 在它不支持的 CPU / OS 上运行。

减少并发、关闭暂不使用的自动截图/预热/主动话题，先确认纯文字聊天能运行。若需要调整 Windows ANGLE 图形后端，请先依据诊断判断问题，避免盲目更改导致渲染异常。

## 反馈问题

提供版本、系统与架构、复现步骤、使用的渠道/模型名称、是否多窗口、错误类型和时间。可以附经过检查的脱敏诊断。

不要附 API Key、Cookie、Token、完整提示词、个人聊天、图片、日记、数据库或包含这些信息的原始日志。先确认问题是否能在最小配置重现。
