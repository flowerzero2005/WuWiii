# 使用指南

## 角色与聊天

在模型设置中选择或导入你有使用权的 Live2D / VRM 角色。动作、表情与合成动作卡应先在设置页预览，再设置情绪触发。不同模型的动作 ID 与表情名不通用。

快捷聊天栏与正式聊天窗口可以分别拖动消息区和输入区之间的分隔条。输入区实际高度随拖动变化，底部工具栏保持位置；最小高度防止遮挡发送按钮。两套比例分别保存。

点击输入区的“拆出输入”，或将该按钮拖到原窗口外，可打开独立输入窗口。点击“收回输入”，或将独立窗口标题区域拖回原会话的输入区域，可合并回来。发送仍由原会话完成，拆出期间原输入区保持只读。

草稿和附件按用户、会话和聊天表面保存，重启后可恢复；同时最多保存 8 个草稿范围，附件合计上限 40 MiB。达到容量时会提示，未发送的旧草稿不会自动被删除。发送结果未知时，恢复草稿保持只读且不会自动重发：先核对原会话，再使用界面提供的丢弃操作。保存或同步失败时应重试成功后再关闭。

## 五个主要机体模块

| 模块 | 需要配置什么 |
| --- | --- |
| 思考 | 聊天服务商、模型和角色提示词 |
| 语音 | TTS 服务商、音色及输出设置 |
| 听觉 | 语音识别服务和输入方式；按需允许麦克风 |
| 视觉 | 视觉渠道、模型与图片/截图设置 |
| 联网搜索 | 搜索服务和预算；聊天模型本身不等于搜索服务 |

宽窗口主要入口为首行思考/语音、次行听觉/视觉/联网搜索；其他能力位于后续入口，窄窗口使用单列。

## 图片与截图

先配置并开启视觉，再在聊天里选择图片或主动截图。视觉可使用官方协议、自配阿里云、OpenAI 兼容或 Gemini 原生渠道；本地兼容模型必须实际支持视觉。

当前单次最多 4 张图片，每张不超过 10 MiB，支持 PNG、JPEG、WebP、GIF。供应商可能有更严格的限制。上传前检查预览，确认未包含密码、支付页面或其他不打算发送的内容。

自动截图是单独的开关，默认关闭；开启前选择来源与频率。关闭视觉或变更账号、服务商、价格授权会停止旧采集/请求。自动采集只保留短期文字理解摘要；模型请求期间图片仍会发送给你选定的视觉服务。没有摄像头功能。

群聊目前以文字为主，不支持在群聊直接上传图片。消费记录能关联群聊回合不代表群聊图片入口已经开放。

## 主动话题、心声与日记

主动话题开启后，按最新用户消息、普通回复或主动回复的完成时间重新等待，不应在刚回复完时立即连发。修改间隔、暂停恢复和会话变化会重排等待。

心声预热开启后，只会在当前情境确有必要时为已完成且可见的回复尝试生成心声；失败或取消时不保证生成成功。语言按当前回合主语言约束。心声服务可以与主聊天模型不同，费用也单独计算。

日记的确认、删除或放弃会保存到对应用户/角色数据范围。遇到保存失败提示时，先重试并确认成功，再退出应用。分享诊断时不要直接导出日记全文。

## 群聊剧本

在剧本设置页组织章节、目标和解锁条件。自动评估通过模型对对话证据作语义判断，当前幕与推进信息在剧本/旁白中展示，条件不局限于关键词。

可回退或重开当前幕，同时保留历史消息。自动评估和后幕生成分别是可选开关，默认关闭；后幕先生成草案，用户接受后才追加。模型判断可能出错，先检查进度和草案，再接受推进。

## 联网搜索

搜索有缓存、取消与回合预算。官方协议默认每回合一次真实上游调用，上限两次；失败和备用也占调用次数，缓存命中不产生新请求。服务不可用时检查设置或停用搜索，继续纯文字聊天。
