# 贡献与隐私

## 提交前

1. 改动围绕一个具体问题，说明行为变化和复现方法。
2. 运行相关测试、类型检查与 lint；审查自动格式化后的 diff。
3. 保留工作区清单与锁文件一致，新增共享类型同时更新使用方。
4. 检查暂存文件中没有个人配置、密钥、服务端材料或生成文件。

不得提交 `node_modules`、缓存、编译输出、安装包、真实 `.env`、用户数据或第三方模型权重。文件已被 Git 追踪后，新增忽略规则并不会自动移除它；提交前仍要检查实际文件清单。

使用测试 fixture 时采用本机回环地址或 `.invalid` 示例域名与明显的测试值，不能从真实请求复制认证头。环境变量名称示例不等于真实秘密。

## 数据和网络

应用的角色、设置、聊天、记忆和日记涉及本机持久化数据。开发版使用独立数据目录；浏览器来源、用户/角色范围和窗口同步会影响读取哪份数据。备份或分享这些数据前先判断是否包含私人内容。

“本地聊天”只说明聊天模型在哪里运行。若另一个模块使用远端语音、视觉、搜索或心声，它仍会把该功能需要的数据发送到所选服务。自动截图需明确开启，原图与文字摘要也可能含隐私。

API Key 和客户端本机设置不应被当作服务端密钥保险箱；不要把私人密钥共享给其他开发者。若凭据误提交，应立即轮换，并处理历史记录，不能只删当前文件。

## 许可证

保留根 MIT 许可证、Project AIRI 作者信息和第三方声明。新增素材要确认授权与分发范围；Live2D SDK、VRM / Live2D 模型、字体和媒体按各自许可证使用。私有仓库不免除这些要求。
