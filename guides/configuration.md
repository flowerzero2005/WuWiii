# 配置与费用

## 自配服务

先在服务商设置中填写 Base URL、模型与密钥，再在相应机体模块选择它。各模块可以使用不同服务商：例如本地聊天、自配语音与自配视觉。密钥在本机配置，不写入 README、截图、测试 fixture 或提交。

OpenAI 兼容只是协议类型，不保证每个模型支持图片、工具、流式输出或语音。以服务商和模型实际能力为准。阿里云和 Gemini 使用对应视觉设置；本地 Ollama / LM Studio 可通过其兼容接口接入支持视觉的模型。

## 可选的本机服务地址

本开发端默认官方协议 API 为 `http://127.0.0.1:3000`，关联游戏服务为 `http://127.0.0.1:3001`。仓库没有这些服务的生产实现，地址只是本地配置缺省值。

需要联调自己有权使用的兼容测试服务时，可复制桌面目录的 `.env.example` 为 `.env.local`，填写测试地址并重新启动开发端：

```dotenv
VITE_SERVER_URL=http://127.0.0.1:3000
VITE_TURTLE_SOUP_URL=http://127.0.0.1:3001/
```

`VITE_` 变量可能被编译进渲染器，**不能放供应商私钥或服务端秘密**。模型 API Key 通过应用设置配置。开发数据目录与正式版分开，开发版不开启官方更新。

## 哪些情况产生费用

| 用法 | 费用来源 |
| --- | --- |
| 纯本地聊天、纯本地能力 | 不产生官方服务点数；运行消耗本机资源 |
| 用户自己的 API | 由该供应商或服务商计费，不记为官方能力扣费 |
| 本地聊天搭配官方语音/视觉/心声/搜索 | 使用的每项官方能力按其当前报价独立计费 |
| 官方聊天、剧本评估与后幕生成 | 按所选官方模型及对应后台用途计费 |

官方能力需要兼容服务提供登录、报价、余额与账本。没有该服务时，本源码仓库不能提供真实官方余额或结算。使用真实第三方 API 同样可能产生费用，即使客户端显示为自配渠道。

个人主页显示服务发布的当前中文价格和消费记录，不在客户端硬编码正式售价。人工视觉关联对应聊天消费，剧本后台消费关联群聊回合，自动截图保留独立用途。成功、失败、中止、退款和重复请求都需要与服务端账本一起验证。

视觉开启与自动截图开启是两件事。服务商、账号或价格变更后需要重新核对授权；取消模型请求不代表供应商一定尚未处理请求，实际退款以服务合同与账本为准。
